# Title Logo

`title-logo.png` is the game's title banner, referenced by `index.html`.
If this file is ever removed, a stone-carved placeholder box with a skull
icon will show in its place instead.

# Backstory Comic Panels

The 5-slide backstory click-through expects these files (comic-book style
art, ~1200x900px / 4:3 landscape panels work best):

    backstory-1.png   Carl & Princess Donut, an ordinary night
    backstory-2.png   Carl fleeing his apartment as the sky splits open
    backstory-3.png   The city unraveling into dungeon architecture
    backstory-4.png   The alien dungeon archway, "Welcome, Contestants"
    backstory-5.png   Carl & Donut stepping through the door into Level 1

Until a given file exists, that scene shows a placeholder panel with a
skull icon and the expected file path.
